# 技能编写与导入指南

技能（Skill）是给 Agent 用的**方法论知识包**：教 Agent 在特定场景下"按什么步骤、守什么约束"做事。技能保存在统一预设库中（`prompt_presets`，type=skill），个人技能导入/保存即可用；公开发布到广场需通过审核。

## 两种创建方式

技能入口只有两种，没有手工表单新建：

### 1. 上传整包（推荐用于迁移外部技能）

预设中心 →「上传技能」，支持**文件夹**或 **ZIP 压缩包**，对齐主流 Agent 技能整包格式：

- 包内必须含 **SKILL.md**，文件开头为 YAML frontmatter（`name` 技能名、`description` 何时使用，均必填）
- 其余文本文件（`references/` 参考文档、`scripts/` 脚本等）作为**附件资源**一并保存，Agent 加载技能后会看到资源清单，按需读取原文
- 二进制文件（图片等）与超限文件（单文件 10 万字符 / 总量 30 万字符 / 最多 50 个）自动跳过并提示
- 解析预览确认后直接落库，当前会话立即可用；同名技能会报冲突，需改名后重传

### 2. 对话中让 Agent 处理

在画布 Agent 面板或对话页发起：

- **创作**："帮我做一个分镜师技能"——Agent 加载官方技能「技能创作」，访谈需求、起草技能卡，经你确认后保存
- **转译**：把外部技能文本粘贴给 Agent——官方技能「技能转译」按本产品能力改写（脚本意图改写为方法论步骤、外部工具映射到产品内置工具或删除、外文转中文），并给出转译报告；价值完全依赖脚本的技能会被如实告知"无法有效转译"

## 技能卡四字段

| 字段 | 说明 |
| --- | --- |
| name | 唯一技能名，与已有技能不得同名，见名知义 |
| tag | 2-4 字短标识，对话输入 `/` 后用于快速对齐，可空 |
| description | **"何时使用"触发行**——技能清单只列名称+本行，Agent 据此决定是否加载该技能。用"当用户……时使用"句式并点出具体场景，≤60 字 |
| content | 正文方法论，建议结构：适用场景 → 步骤/原则 → 约束与禁忌 → 示例，上限 20000 字符 |

description 是技能能否被正确触发的关键：写得空泛（如"创作助手"）Agent 难以判断何时加载；写得具体（如"规划或调整分镜数量、镜头时长与排列顺序时使用"）命中率高。

## 附件资源与脚本边界

- 附件资源按需读取：`agent_load_skill` 结果只附资源清单（路径+大小），Agent 需要时用 `agent_read_skill_file` 读取原文，不占常驻上下文
- **脚本只是存档文本，当前不会被执行**，Agent 也无法联网、读写本地文件，只能调用产品内置工具（画布节点操作、图片/视频生成、成片合成等）
- 依赖脚本运行才能用的技能（如文档解析类）当前无法发挥完整价值；脚本本地执行能力规划在后续 MCP 化阶段支持

## allowed-tools 权限声明（可选）

SKILL.md frontmatter 可声明 `allowed-tools`（字符串逗号分隔或 YAML 数组）。条目能对应到本产品工具名（画布工具 `agent_*` / `storyboard_*` 与对话工具 `generate_image` / `generate_video` 等）的会生成工具白名单：技能加载后，白名单之外的内置工具调用会在内核层被直接拒绝；声明了但映射不到产品工具的条目不生效（建议经「技能转译」重新映射）。未声明该字段的技能不限制工具。

## 导出与分享

- **导出**：预设中心"我的预设"列表中技能行点"导出"，得到标准 SKILL.md 文件，可在其他支持该格式的 Agent 中使用
- **投稿**：个人技能默认仅自己可用；点"投稿"提交公开审核，过审后进入广场供所有用户使用

## 管理

预设中心"我的预设"可编辑、删除自己的技能；技能行有**启用开关**，停用后不进入 Agent 技能清单（正在进行的会话刷新缓存后生效）。广场画廊可浏览官方与已过审技能。对话中输入 `/` 可按 tag 或名称快速检索并调用技能。
