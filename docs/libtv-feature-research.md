# LibTV（liblib.tv）功能调研与复刻方案

调研 LibTV 的产品设计与功能清单，评估与本项目无限画布的差距，给出面向"辅助短剧生成"的复刻路线。

## 一、产品概况

LibTV 是哩布哩布 AI（LiblibAI）推出的 AI 视频创作平台（liblib.tv），定位"专业视频创作工具"，上线首日访问量破 10 万。核心形态是**无限画布 + 节点式工作流**，目标是在一个界面里完成"剧本撰写 → 分镜设计 → 图片生成 → 视频生成"，避免多工具切换。支持两种入口：

- **人类入口**：在无限画布上拖节点、连线、逐步生成；
- **Agent 入口**：官方开源 `libtv-skills`（OpenClaw / 飞书插件 / KimiClaw 安装，access_key 授权），用自然语言指令全自动生成，官方建议测试期控制在 3 分钟内的内容。

模型聚合：Seedance 2.5（多参创作、音视频直出 30s、长视频可到 5 分钟）、Wan 3.0（改写视频画面/剧情/环境）、MiniMax H3、可灵 O3/3.0、Midjourney V7/Niji 7、Lib Nano（自研）、Seedream 5.0、Hailuo、Vidu、Pixverse 等 20+ 款，可自由切换。

## 二、无限画布与节点系统

### 画布交互

- **双击画布空白处**直接新建节点（主入口），左侧工具栏有"添加节点 / 工具箱 / 我的素材 / 历史素材"；
- 支持直接把本地图片、视频、音频文件拖入画布成节点；
- 节点可自由拖拽、分叉组合、并行编辑，内容可**反复引用和二次加工**（同一张底图连续生成多版风格图、多条视频）；
- 节点**打组**后组是一个整体：点组右侧"+"直接创建下游节点，引用整组内容；
- 整套流程可**打组保存、一键重复执行**（工作流复用）；
- 画布可分享给他人实时查看，可发布到社区；生成历史保存在"历史素材"中随时调用。

### 五种基础节点

| 节点 | 作用 |
| --- | --- |
| 文本 | 剧情描述、角色设定（风格/外貌/服饰/动态/背景五要素）；连到生成器后内容**自动并入提示词** |
| 图片 | 上传或生成图片，是所有图像工具和图生视频的载体 |
| 视频 | 图生视频、音生视频、视频后处理 |
| 音频 | 音频素材、音频生视频 |
| 脚本 | 输入剧情描述或上传角色参考图 → 自动生成结构化分镜脚本；支持**一键批量转分镜图 → 批量转视频片段**，每条可单独调整重新生成 |

### 智能引用机制（LibTV 画布的灵魂）

- 图片节点点击"图生图"，**右侧自动产生新节点**，参考图自动引用到新节点的生成器中；
- 点击图片节点右侧"+"拉出视频节点，上游图像自动作为生成输入；
- 上游文本节点连到生成器后，文本内容自动成为提示词的一部分；
- 生成的结果回填后自动连线，用户几乎不需要手动管理连线。

### Slash 快捷指令（图像生成器内输入 "/" 调出）

- 多机位 9 宫格
- 剧情推演 4 宫格
- 25 宫格连贯分镜
- 电影级光影校正
- 角色 3 视图生成
- 画面推演（3 秒后 / 5 秒前）

## 三、AI 能力清单

### 图像工具集（10 项）

增强（2/4/6 倍高清放大）、扩图、多角度（15 个环绕点位视角生成）、打光（26 个主光点位 + 智能模式）、重绘、擦除、抠图、宫格切分、标注、裁剪。

### 视频工具集

高清放大（2/4/6 倍）、帧率提升（30/60/90fps）、视频分镜解析、基础视频剪辑（片段裁取）。

### 三个独家/特色功能

| 功能 | 说明 |
| --- | --- |
| **导演台**（独家） | 3D 虚拟场景，精准控制空间，在虚拟场景中布景调度 |
| **逐帧拉片**（独家） | 上传参考视频逐帧分析，作为生成时的镜头语言快捷参考 |
| **片段重拍** | 对某条视频切换到工作流视图，单独修改某个镜头的提示词/特效后重新生成该片段，无需整条返工 |

另有：首尾帧提取再生成、裂变九宫格、批量生成视频（顶部操作，基于脚本信息自动将分镜图转为合适的视频）。

## 四、官方推荐短剧工作流

1. 新建画布，文本节点输入故事大纲/剧本（或双击建脚本节点）；
2. 脚本节点"角色生成分镜脚本"，上传角色三视图锁定角色一致性；
3. "生成分镜"批量产出分镜图，逐条调整；
4. 分镜图连视频节点批量图生视频（或点顶部"批量生成视频"）；
5. 片段不满意用"片段重拍"单镜头重做；
6. 下载片段导入剪映等外部工具加音乐/字幕/拼接（LibTV 内置剪辑仍在完善）。

第三方教程总结的典型链路：剧本 → AI 画布分镜 → 锁定一致角色 → 图生视频 → 对口型 → 拼接加音乐字幕。

## 五、与本项目现状的差距分析

本项目已有：自研 InfiniteCanvas（DOM/SVG，缩放/平移/连线/多选/历史/小地图/吸附对齐/导入导出）、8 种节点（text/image/video/audio/config/tts/subtitle/compose）、连线类型校验、生成任务回填（`canvas-generation.ts`）、任务队列、localforage 持久化、素材库、图像后处理（裁剪/分割/旋转/放大/蒙版）、3D 场景导演台（three.js + `routes/scenes.py`）、项目制创作（剧本/角色/场景/分镜/时间线/向导，`routes/projects.py`）。**画布底座和短剧数据模型两边其实已经对齐，缺口集中在"创作编排层"。**

| # | LibTV 能力 | 本项目现状 | 差距 |
| --- | --- | --- | --- |
| 1 | 双击空白建节点、本地文件拖入 | 工具栏添加、素材库拖入 | 交互补齐，成本低 |
| 2 | 智能引用：点"+"自动派生下游节点并引用上游 | 已支持连线收集上游 + `@[node:xxx]` 引用，但需手动连线、手动填写引用 | 缺"节点/组右侧 + 一键派生 + 自动连线" |
| 3 | 脚本节点：剧情→分镜脚本→批量分镜图→批量视频 | 项目画布（ProjectCanvasView）有 script 节点和向导，但**主画布未打通批量链路** | 主画布补脚本节点 + 批量执行 |
| 4 | Slash 快捷指令面板 | 已有 GenerationQuickPanel | 扩展为 slash 指令入口 |
| 5 | 宫格工具：角色三视图/多机位九宫格/剧情推演四宫格/25宫格连贯分镜/画面推演 | 无 | 纯 prompt 模板 + 多任务并发 + 宫格切分（`canvas-image-ops.ts` 已有分割），全是前端编排 |
| 6 | 图像工具：扩图/擦除/重绘/抠图/打光/多角度/标注 | 有裁剪/分割/旋转/放大/蒙版 | 按需补齐（打光、多角度可用 prompt 模板实现） |
| 7 | 视频工具：帧率提升/首尾帧提取/视频分镜解析 | 有放大、video2video 参考模式 | 首尾帧提取再生成价值最高 |
| 8 | 片段重拍（工作流视图单镜头重生成） | compose 节点合成已有，但缺"从成片定位回某镜头单点重生成" | 短剧场景核心痛点，建议做 |
| 9 | 组作为整体引用、工作流一键重复执行 | 有 StepGroup 分组与执行顺序分析 | 组引用与批量重跑 |
| 10 | 导演台 3D 虚拟场景 | **已有** 3D 场景导演台 | 增强：与分镜联动输出首帧图/机位提示词 |
| 11 | 逐帧拉片 | 无 | 可后置，或用 video2video 参考模式部分替代 |
| 12 | 画布分享/社区/Agent 入口 | 无 | 产品化功能，远期 |
| 13 | 配音/字幕/合成节点 | **本项目反而领先**（tts/subtitle/compose 节点 + 后端 audio/subtitle service） | 无 |

## 六、建议复刻路线（按短剧价值排序）

### P0 短剧主链路（核心价值）

1. **脚本节点**：剧情描述/角色图 → 生成结构化分镜脚本（JSON：镜头号、景别、机位、画面描述、台词）→ 回填为可编辑列表。后端可复用 `services/project/script_service.py` + LLM。
2. **批量分镜图**：脚本逐条 + 角色参考图 → 并发创建图片任务（复用 taskQueue，每类并发上限已有）→ 每条结果独立节点、可单条重生成。
3. **批量图生视频**：分镜图批量派生视频节点（沿用视频模型与 video2video 能力）。
4. **片段重拍**：每个视频节点记录来源（分镜号/提示词/参考图），支持"改提示词仅重生成该镜头"。

### P1 画布交互对齐

1. 双击空白处弹出节点创建菜单；
2. 节点右侧"+"派生下游节点（图→视频、文本→图等）并自动连线、自动引用；
3. 组整体引用（组"+"派生）；工作流保存/一键重跑（基于 `canvas-flow-analyzer.ts` 的执行顺序）；
4. slash 指令面板（扩展 GenerationQuickPanel）。

### P2 角色一致性工具包（前端编排为主）

角色三视图、多机位九宫格、剧情推演四宫格、25 宫格连贯分镜、画面推演（±秒）。实现模式统一：prompt 模板 → 并发生成 → 宫格切分成独立节点（切分能力已有）。

### P3 工具补齐

扩图、擦除/抠图、打光（光位模板）、多角度（机位模板）、首尾帧提取再生成、帧率提升（视上游 API 能力）。

### P4 增强项

逐帧拉片（上传参考视频抽帧 + 多模态分析 → 生成镜头参考卡）；导演台与分镜联动（3D 场景输出机位图作为分镜首帧）。

### 暂不建议做

画布实时分享、社区、Agent/CLI 入口——对"辅助做短剧"非核心，且成本高。
