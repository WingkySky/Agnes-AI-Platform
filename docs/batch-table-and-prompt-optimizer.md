# 批量创作表节点 + 提示词优化器 功能文档

> 本批三项功能：模型能力合同收敛、画布批量创作表节点、提示词优化器。接口细节见 `API.md` 第 18 章，设计决策见 `.zcode/plans/` 下设计文档（gitignored）。

## 一、模型能力合同（capability_service）

**解决什么问题**：模型特例（参考图上限、水印参数、尺寸规则）此前散在生成代码的分支里，模型接入越多分支越乱。现收敛为后端唯一合同层 `backend/app/services/capability_service.py`：

```
三级优先：DB gen_params 显式配置（逐键覆盖）> 模型名自动画像 > 默认兜底
```

- 现有画像：`seedream*`（watermark 可关 + 尺寸归一化 seedream 规则）、`agnes-image-2*`（参考图上限 6，上游实测约束，官方文档未标注）。
- **新增模型特例 = 在 `detect_model_profile` 加一条画像分支**，不改生成代码；管理员也可对单个模型在后台写 `gen_params` 显式覆盖。
- 下发通道复用 `GET /api/config` 的 `models[].gen_params`，前端统一走 `useModelsStore().getModelGenParams(modelId)`；不要在前端新造能力判断入口。

## 二、批量创作表节点（画布 table 节点）

**形态**：画布上的表格节点，「N 行 × M 参考图列」矩阵批量生图。

**入槽三通道**：
1. 单元格点击 → 选文件；
2. 图片文件直接拖入单元格；
3. 列头圆点句柄拖线到画布上有内容的图片节点 → 按列填充自上而下首个空槽（同时建血缘连线，删除表格节点自动清理）。

**行与列**：
- 列数 = min(6, 所选模型合同参考图上限)；模型切换自动截断/补齐各行槽位。
- 全局提示词非空时与行提示词按「全局 + 行」追加拼接。
- 操作预设：**批量换装**（2 列，含服装替换模板：参考图 1 为人物原图、参考图 2 为目标服装，保持身份/姿态/背景不变）、**创意生图**（3 列）、自定义。
- 行级开关：取消勾选的行不参与提交。

**提交与结果**：
- 「生成 N 行」前逐行校验（提示词非空、参考图不超额），不合格行红框拦截，合格行照常提交（部分提交可用）。
- 每行独立建图片任务（走现有画布生成管线与任务队列），结果落独立图片节点并连线回表格。
- 行状态徽标：待生成/排队/生成中/完成/失败；失败行可单独重试（重新提交该行），不影响其他行。

## 三、提示词优化器

**入口四处**：图片生成页、视频生成页（风格/特效库旁「优化提示词」按钮）、画布节点 composer（✦ 按钮）、批量创作表行提示词（✦ 小按钮）。

**交互（每模式独立面板）**：五个模式各自缓存结果与用户编辑——首次切到某模式自动生成，来回切换立即呈现各自的最新结果（含已编辑文本与选中变体），「应用」取当前面板内容；失败按面板独立重试。输出语言钉死：中文输入 → 全字段简体中文（禁止英文提示词），非中文输入跟随输入语言。

**五种模式**：
| 模式 | 说明 |
|---|---|
| 扩展想法 | 保留核心意图，补充主体/环境/构图/光影细节 |
| 精修提示词 | 修语病与冲突描述，重排为模型易读结构 |
| 强化风格 | 注入媒介质感、镜头语言、色调氛围 |
| 适配模型 | 按目标模型方言改写（如 flux 偏好自然长句、gpt-image 族不支持独立负向） |
| 结合参考素材 | 围绕参考素材明确「保留什么、改变什么」 |

**返回结构**：正向提示词（可编辑）、负向提示词、关键变化说明、假设声明（明确 AI 做了哪些主观决策）、最多 2 个备选版本。

**交互约定**：优化结果应用前不改动调用方原输入；视频页应用时正/负向分别回填对应输入框；失败弹窗内可重试。
